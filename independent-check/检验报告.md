## 结论

未发现任何错误。Lean 形式化可以完整编译并通过内核重放。三个主要定理的形式化陈述忠实于论文的数学含义。第三部分（树宽二的二次时间反例）的论证经人工逐行复核，关键数值前提在全规模实例上独立验算，均成立。该反例确实否定了 Fabian–Morris–Szabó 的猜想 8.8。

鉴于结论意义重大，仍建议由该领域专家进行正式同行评审。

**定理陈述是否表达了论文的意思**（逐一阅读的定义）：

- `Witness` / `step`：H 去掉一条边后的单射、非诱导拷贝，同一轮的所有拷贝读同一张旧图，与论文 (1) 式和 FMS 原文一致。
- `stabilizationTime`、`maxTime`：首个稳定时刻；在 `Fin n` 上所有简单图中取最大值。
- `HasLinearUpper`、`HasLinearOrder`、`HasQuadraticOrder`：用整数常数表达的标准渐近含义。
- `TreeSemantics.WidthLE`：标准树分解（宽度、覆盖顶点和边、每个顶点所在的袋在树上连通）。
- `Theta.rule`：第 i 臂恰有 Lᵢ−1 个内部顶点、Lᵢ 条边。
- FMS 的线性下界（Theorem 1.4）在项目内证明，不是作为公理引入的。
- `theorem_III_1` 和 `counterexample` 直接断言存在连通、树宽 ≤2、`¬HasLinearUpper` 的规则。只要上述定义正确，这就是对猜想的完整反驳。

## 2. 原猜想与定义（arXiv:2311.18786v2）

- 猜想 8.8 原文："Any graph H with tw(H)=2 has M_H(n)=O(n)."，没有附加条件。
- 原文中 H-过程、τ_H、M_H(n) 的定义与本文一致。
- 反例是 2-连通、最小度为 2 的规则，即使按 FMS 文中"只考虑连通 H"的约定，也落在猜想范围内。

### 3.1 第二部分与附录 A 逐行审读

| 环节 | 核对要点 | 结论 |
|---|---|---|
| 路由分解 | 基点之间没有边（每条边都有度二端点），所以基点的邻居都是度二顶点；两个不同基点之间的路由长度 ≥2，回到原基点的路由长度 ≥3；圈的情形单独取一个基点 | 正确 |
| 度二移动 | 把度二角色换到外部点 z，只缺 z–f(j) 一条边；z ∉ W 保证单射；多个外部点可在同一轮并行 | 正确 |
| Lemma II.2（长路由） | P 走偶数位、Q 走奇数位，经度二内点每步移动两格，分别到 x₀ 和 x₃；x₁、x₂ 放在 p、q 时只缺 pq；x₀ = x₃ 的回路情形也成立 | 正确 |
| Lemma II.2（短路由） | 由连通性，分量 C 中存在关联长路由的基点 x₀；用 p₀ 替换 w 得到满拷贝 W′；旧的 w 像在 W′ 外，可沿 C 传播；q ∉ W′（P、Q 不交）；总轮数 ≤ 2\|C\| ≤ 2h | 正确 |
| 低度计费 | 付费时度数 < J，且此前付过费的边仍与它关联，所以每个顶点至多付 J−1 次；高度时 W 外邻居 ≥ 3h−1−(h−1) = 2h，足够选出不交的 P、Q | 正确 |
| 二部无桥情形 | H−e 连通，所以分量之间不合并；若分量原本二部，见证保持原二分；吸收时把度二角色放到新顶点，其余角色按染色放入两岸；交换相邻度二角色后，恰好两条边落在岸内，四个端点互不相同 | 正确 |
| 团块合并 | 块是团，所以新边必跨块；外部点经度二角色一轮内连到整个团，下一轮外部点两两相连；每次合并块数至少减一 | 正确 |
| 只有一条同色边 e₀ 的染色 | 二部带桥时翻转 H−e₀ 的一个分量；非二部但某个 H−e₀ 二部时直接用其染色；两岸各在一轮内成团 | 正确 |
| 一般非二部情形的标记传播 | 若 N(v) 中有相邻的两个点，P 一轮成团；若 N(v) 独立，其余邻居的另一端不会被移动，单射需要 \|P\| ≥ deg v −1；最短奇闭途径长度 ≤ 2h−1，且不会在内点立即折返，所以由整条路由组成；最终 P 或 Q 成团，x、y 被吸收 | 正确 |
| 附录 A 块内转移 | 基本角色数 ≥ c−2，中点角色从 T 中取，剩余 ≥ h−c−1 = m−1 个位置；跨块第一条边两轮内填满两块之间的全部点对；大小 ≥ c+1 的块中一条内边两轮内填满该块 | 正确 |
| 附录 A 合并 | K = 2h + c² − 1 保证 W 外至少 h + c² 个邻居；r 轮内看到整个 A；丢弃大小恰为 c 的块中的点（≤ c² 个），剩余 ≥ h 个可作为新块的 T | 正确 |
| 附录 A 计数 | 块内诞生 ≤ b₀J₀，其中 b₀ = max{3, C(c,2)}；第一次接触若既不低度计费也不触发合并会产生矛盾；每对块的诞生集中在三个连续轮次 | 正确，与 Lean 的 `displayed_budget` 逐项一致 |

两处叙述较简略，均不影响正确性，Lean 中都有完整处理：

- 二部吸收中，同时接触两岸的顶点没有单独讨论。它会同时得到两岸的全部边，等价于产生岸内边，落入后续的"岸内有边"情形。
- 附录 A 关于"等待区间前两轮中的第一次接触"的那句话写得较简略。

**针对性随机测试（Lemma II.2 的 2h 轮上界）**：8 种规则，包括 θ(2,2,3)、θ(2,3,3)、θ(2,2,4)、θ(2,2,5)、C₄、C₅、蝴蝶结图、带悬挂路径（含桥）的 K₂,₃，覆盖短路由的困难分支。对每条规则边的两个方向，随机加入额外边，共 660 次测试。每次都在 2h 轮内使 P–Q 完全连接，0 次失败。

## 5. 检验的局限

- 渐近结论（线性、二次）无法用有限数值检验，只能依靠 Lean 证明。
- 普通宿主图上"不存在多余见证"这一方向（Lemma III.4/III.5 的 ⊆ 方向）规模过大，无法暴力穷举。它由 Lean 证明、人工审读和第 4 节的不等式验算共同支撑。
- θ 闭包模拟在到达时间上限时中止，未覆盖 17–18 个顶点的全部情形。中止前未出现任何失败。
